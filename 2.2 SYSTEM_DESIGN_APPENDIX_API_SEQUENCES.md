### 2. `scheduleAppointment`

`POST /appointment-scheduler/v1/appointments`

~~~mermaid
sequenceDiagram
    actor User as Dealership user
    participant API as Scheduler API
    participant App as Appointment service
    participant DB as PostgreSQL
    User->>API: POST /appointment-scheduler/v1/appointments
    API->>App: validate command and actor context
    App->>DB: transaction: validate scope, customer/vehicle, requirements and availability
    App->>DB: insert appointment, two reservations, audit event and idempotency record
    alt interval constraints succeed
        DB-->>App: committed appointment
        App-->>API: 201 Created
    else replay, conflict, or invalid data
        DB-->>App: prior result / constraint error
        App-->>API: 200 / 409 / 422
    end
    API-->>User: response
~~~
